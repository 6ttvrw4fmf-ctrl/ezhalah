# CHECKS INSIDE THE REQUIRED `npm test` THAT CAN REACH THE LIVE ENDPOINT.
#
# Routine #10, ops_incident #104, 2026-09-06. `npm test` is the REQUIRED status check on every PR, so
# its verdict must depend ONLY on the diff. A check that cannot answer without asking production
# breaks that by construction — measured 2026-09-06, four such checks flipped on UNCHANGED code.
#
# Every file that transitively imports scripts/lib/public-supabase.ts and still runs in `npm test`
# must appear here with its MEASURED verdict. scripts/verify-required-suite-is-hermetic.ts fails on
# any candidate that is not listed, so a new live-reaching check cannot enter the required suite
# unnoticed — which is the point: this file exists to stop the class GROWING, not to bless it.
#
# Format:  filename | production-dependent | offline-safe  | the measurement
#
# HOW TO MEASURE (one command, no production access needed — a blackholed endpoint):
#   node --experimental-strip-types scripts/<file>.ts >/dev/null 2>&1; echo "normal=$?"
#   SUPABASE_URL="https://127.0.0.1:9" node --experimental-strip-types scripts/<file>.ts >/dev/null 2>&1; echo "blackhole=$?"
# Different exit codes ⇒ production-dependent. Same ⇒ offline-safe (it imports the resolver but its
# verdict does not depend on reaching it — typically a meta-check ABOUT the resolver).
#
# THE `production-dependent` LIST MAY ONLY SHRINK. It is a ratchet, exactly like
# scripts/mutation-proof-grandfathered.txt: the size is pinned in the barrier so adding a name is a
# reviewed source change, never a quiet append. Shrink it by SPLITTING the check — the hermetic
# predicate and its mutation proofs stay in `npm test`, the live assertion moves to a workflow home
# declared in scripts/test-exclusions.txt, and the offline half proves via liveHalfProblems() that
# the home really invokes it. Three checks were split that way on 2026-09-06; see
# scripts/verify-af-attribute-views-cover-every-platform.ts for the worked shape.
#
# NEVER shrink this list by WEAKENING a check — every one of these fails CLOSED on an unreachable
# endpoint, which is correct and must stay (AGENTS.md: A FAILED FETCH IS NOT AN EMPTY ANSWER). The
# problem is never that they are too strict; it is that they are in the wrong job.
